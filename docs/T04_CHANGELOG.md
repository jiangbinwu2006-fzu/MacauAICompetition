# T04 四语界面修改日志

## 完成内容

- 游客工作台支持简体中文、繁体中文、英文和葡文即时切换，无需刷新页面。
- 四语覆盖品牌栏、游客会话提示、偏好表单、校验与操作提示、目录筛选、地图图例和点位详情。
- 点位名称与简介按当前语言重新请求后端目录；区域、分类、开放时间、无障碍状态、来源机构和有效期均同步本地化。
- 偏好表单中的语言选项与页面语言双向同步，切换后同时更新页面 `lang` 属性。
- 高德地图在简体中文时使用中文底图，其余语言使用高德支持的英文底图；业务点位覆盖物继续显示当前选择语言。
- 翻译缺失时执行“当前语言 → 繁体中文 → 简体中文”回退；后端目录也使用相同的繁中、简中兜底顺序。
- 开放空间、24 小时、按演出或展览安排、服务依实际情况及星期闭馆等目录数据增加四语显示转换。
