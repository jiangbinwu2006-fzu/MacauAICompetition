# v1.0.0 发布说明

发布日期：2026-07-28

## 发布范围

本版本实现澳门文旅智联非商业游客服务闭环：

`Guest -> Preferences -> Route -> Natural POI -> Event -> Reroute -> Undo/Restore -> Feedback -> Ops`

## 验证状态

- 后端自动化测试：10 项通过，0 失败
- 前端生产构建：Vite 56 模块通过
- 真实改线测试：整区封锁、多点冲突、必去点安全挂起、当前位置重排通过
- 响应式测试：桌面端及 `390x844` 移动端无定位按钮溢出
- 运行端口：前端 `3001`，后端 `8290`

## 已知限制

- 事件、行程、反馈和看板指标为 Demo 阶段内存数据，后端重启后清空。
- 高德底图仅支持中文和英文模式，繁中和葡文使用英文底图。
- 地图和公交详情取决于运行时高德在线服务。
- Agent 保留原有技术栈；硬约束和路线可行性始终以 Java 路线引擎结果为准。

## 安全说明

本发布包已排除实际 API Key、MySQL 密码、`.env`、`application.yml`、虚拟环境、编译产物、运行数据库与日志。
