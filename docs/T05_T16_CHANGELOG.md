# T05-T16 澳门文旅智联非商业闭环修改日志

更新时间：2026-07-27

## 完成范围

### T05-T07 路线生成、硬约束与地图行程

- Java 后端新增确定性启发式半日路线引擎，支持必去点、出发/结束时间、步行上限、无障碍需求和交通偏好。
- 输出站点顺序、预计到达、停留时间、分段交通、安全缓冲、预计结束时间及来源信息。
- 同时比较步行、公交和组合方案；无可行解时返回明确冲突，不返回伪成功路线。
- 游客端新增行程页，地图使用高德步行/公交服务绘制路线，高德异常时降级为静态折线和文字路线。
- 路线地图使用编号节点，卡片与地图使用同一份行程版本数据。

### T08-T09 自然推荐、时效和安全降级

- 餐饮、补给及普通商户只作为自然 POI，不包含广告标签、付费权重或商业曝光逻辑。
- 推荐排序综合顺路度、兴趣、营业可靠度、无障碍适配和点位多样性。
- 推荐加入前重新校验时间、步行和结束时间，展示新增绕行时间与距离。
- 支持加入路线、稍后提醒、忽略推荐和撤回加入。
- 过期点位由目录查询自动过滤，不进入路线和推荐候选。
- 地图服务异常时返回 `static_fallback` 并保留可读的静态文字行程。

### T10-T12 事件管理、实时提醒与动态改线

- 新增运营事件页，支持封路、暴雨、场馆关闭事件的创建、启用、撤销和过期管理。
- 事件包含等级、影响区域、时间窗、影响点位、版本及模拟标识。
- 新增 SSE 实时推送 `/api/events/stream`，游客端无需刷新即可收到影响提醒。
- 高危事件先提醒游客，不静默自动改线。
- 支持局部改线和全局重排，展示新旧路线的时间、步行距离和抵达变化。
- 支持撤回上次改线及恢复初始行程。

### T13 无障碍与文字导出

- 新增大字体、高对比和简化页面控制。
- 偏好支持低步行、无台阶和安静少拥挤需求。
- 行程支持纯文字预览及 TXT 文件导出。
- 页面使用响应式布局，紧凑屏幕下工具栏、卡片和操作按钮自动换行。

### T14 反馈工单

- 游客可提交数据错误、路线不合理、无障碍问题和人工求助。
- 工单自动关联匿名会话、行程 ID、行程版本及当前事件，不采集手机号等非必要身份数据。
- 运营端可查看、分类和关闭工单。
- 修复跨域配置未放行 `PATCH` 的问题，浏览器现可调用工单关闭接口。

### T15 公益运营看板

- 展示匿名路线数、约束通过率、改线成功率、事件影响数和开放工单数。
- 提供按澳门区域汇总的匿名热力数据，并明确标识为 Demo 匿名聚合数据。
- 支持模拟封路事件一键注入及演示数据一键重置。

### T16 非商业故事线

- 已完成匿名进入、路线生成、自然点位加入、事件注入、SSE 提醒、局部改线、路线对比、撤回和反馈提交故事线。
- 四语界面、来源信息、无障碍显示、纯文字导出和静态降级均已接入同一游客流程。

## 新增接口

- `POST /api/trips`：生成半日路线
- `GET /api/trips/{tripId}`：读取行程
- `POST /api/trips/{tripId}/recommendations/{poiCode}`：加入自然推荐
- `POST /api/trips/{tripId}/recommendations/{poiCode}/ignore`：忽略推荐
- `POST /api/trips/{tripId}/reroute`：局部或全局改线
- `POST /api/trips/{tripId}/undo`：撤回上次操作
- `POST /api/trips/{tripId}/restore`：恢复初始行程
- `GET /api/events`、`GET /api/events/stream`：事件查询与 SSE 推送
- `POST /api/feedback`：游客提交反馈
- `GET /api/ops/dashboard`：公益运营指标
- `POST /api/ops/events`、`PATCH /api/ops/events/{eventId}/cancel`：事件管理
- `GET /api/ops/feedback`、`PATCH /api/ops/feedback/{feedbackId}`：工单管理
- `POST /api/ops/demo/event`、`POST /api/ops/demo/reset`：Demo 注入与重置
