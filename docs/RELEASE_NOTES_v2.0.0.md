# v2.0.0 发布说明

发布日期：2026-07-30

## 发布定位

v2.0.0 是澳门文旅智联非商业公益闭环的第二版，重点完善澳门真实地图展示、当前位置路线规划、智能公交信息和稳定演示能力。

## 主要更新

- 恢复并校准 60 个澳门四语分类点位，使用高德真实地点解析。
- 增加 30 天地点坐标缓存、低并发渐进加载，减少重复地图调用。
- 路线从游客 GPS 或手动当前位置绘制首段，不再以最近景点代替起点。
- 接入智能公交路线展示，包括线路、上车站、途经站、下车站和站点位置。
- 统一路线地图为高德原生风格，移除多余数字节点和重复起点标记。
- 新增关闸口岸一日往返、酒店一日往返两条固定演示路线。
- 加强事件多地点选择、局部改线、整程重排、撤回和恢复能力。
- 增加后端守护与自动恢复脚本，提升现场演示稳定性。
- 补充 60 点位地址核对表和 BUG-01 至 BUG-23 完整修复记录。

## 验证状态

- 前端生产构建：Vite 56 个模块通过。
- 后端自动化测试：12 项通过，0 失败，0 错误。
- 数据库集成：MySQL 连接及测试通过。
- 地图运行验收：全分类显示 60/60 个点位。
- 当前位置路线验收：唯一当前位置标记、唯一终点标记，首段路线正常绘制。
- 服务端口：前端 `3001`，后端 `8290`。

## 安全说明

仓库不包含实际 API Key、MySQL 密码、模型密钥、`.env`、`application.yml`、本机虚拟环境、编译产物或运行日志。

## 当前边界

本版继续聚焦公益游客服务闭环，不包含商户自助入驻、广告投放、赞助、结算、支付或商业流量算法。
