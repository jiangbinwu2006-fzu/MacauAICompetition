# T01 澳门地图与基础数据修改日志

## 本轮修改

### 1. 澳门点位坐标改由高德解析

- 接入高德 `AMap.PlaceSearch` 和 `AMap.Geocoder`。
- 使用目录点位名称向高德查询坐标，不再直接使用目录内人工维护的经纬度绘制标记。
- 仅接受经度 `113.52-113.61`、纬度 `22.10-22.23` 范围内的返回结果，避免同名地点被标记到澳门以外。
- 单次请求设置 4 秒超时，并执行最多 3 次有限重试。
- 高德无结果或请求失败时不使用人工坐标补画，点位仍保留在目录列表中。

### 2. 顶部点位数量改为语言切换

- 删除顶部“60 个有效点位”展示。
- 顶部改为简体中文、繁体中文、英文、葡文切换按钮。
- 删除侧栏内重复的语言切换控件。
- 保持无需刷新即可切换点位内容语言。

### 3. 地图标记尺寸调整

- 保留原有分类图标、颜色和水滴形状。
- 标记尺寸由 `36px` 调整为 `24px`。
- 图标字号由 `13px` 调整为 `9px`。
- 边框由 `3px` 调整为 `2px`，同步减小阴影和定位偏移。
